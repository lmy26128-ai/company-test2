# 핵심 설계 신념

## 1. 자동화는 보조 도구다
스크립트가 생성한 날짜는 **초안**이다.
담당자가 현업 상황(검진기관 일정, 직원 휴직 등)을 반영하여 최종 확정한다.

## 2. 유해인자는 법령 기준이 최우선
매핑 테이블은 `docs/references/유해인자_기준표.md`의 법령 기준을 따른다.
현장 변경(공정 추가/제거)이 있으면 담당자가 매핑 테이블을 먼저 업데이트해야 한다.

## 3. 데이터는 단일 원본에서 관리
파트별 시트(업무설비·생산1·2·3파트)는 `24.7기준최종` 시트의 서브셋이다.
자동화의 기준은 항상 `24.7기준최종` 시트다.

## 4. 개인정보는 최소한으로 처리
자동생성 로직은 주민번호가 없는 `24.7기준최종` 시트만 대상으로 한다.
