# DESIGN.md — 설계 원칙

## 핵심 설계 원칙

### 1. 원본 보존 (Immutable Source)
원본 파일(`data/정기특검+보건증.xlsx`)은 절대 수정하지 않는다.
자동생성 결과는 항상 별도 파일로 출력한다.

### 2. 날짜 추론 우선순위
전년도 → 전전년도 → 기본값(04월) 순으로 탐색.
셀에 텍스트가 섞여 있어도 `YY.MM` 패턴만 추출하여 처리한다.

### 3. 유해인자 매핑의 명시성
매핑 테이블은 스크립트 최상단에 집중 관리하여 유지보수를 단순화한다.
부서+직군+직무 조합으로 우선순위를 부여하고, 위에서부터 첫 매칭을 적용한다.

### 4. 야간 유해인자 분리
`야간` 항목은 특수항목(L열)에는 포함하지 않고,
야간(K열) == "O"인 경우에만 유해인자(M열)에 접두로 추가한다.

### 5. 배치전/배치후 1회 원칙
배치전·배치후는 동일 유해환경 배치 시 1회만 실시한다.
이전 연도에 기록이 있으면 27년에는 자동 생성하지 않는다.
