# FRONTEND.md

## 컴포넌트 구조

```
App
├── SearchBar (사번/성명 입력)
├── EmployeeCard (인적사항, 유해인자, 검진대상여부)
└── CheckupTable (연도별 탭 + 검진 현황)
    └── StatusBadge (완료/예정/초과/미입력)
```

## 상태 표시 규칙 (Excel 원본 색상 기준)

| Excel 색상 | fontColor 값 | 웹 표시 | CSS 클래스 |
|-----------|------------|--------|-----------|
| 검정 글씨 | 0 | 초록 배지 "완료" | `badge.completed` |
| 파란 글씨 | 15773696 | 파란 배지 "예정" | `badge.scheduled` |
| 빨간 글씨 | 255 | 빨간 배지 "초과" | `badge.overdue` |
| 핑크 배경 | 16764159 (Interior) | 카드 핑크 배경 | `card.on-leave` |
