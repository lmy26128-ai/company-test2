# 기능 명세: 건강검진 자동화

## 기능 1. 연도별 검진 날짜 자동생성

### 입력
- 이전 연도(24~26년) 검진 날짜 (YY.MM 형식)
- 일반검진 대상 여부 (J열 = "O")
- 특수항목 유무 (L열 비어있지 않고 "X" 아님)

### 출력 (27년 기준)
| 컬럼 | 생성 규칙 |
|------|-----------|
| 보건증+일검 | 전년도 동월, 없으면 27.04 |
| 배치전 | 신규 배치자만, 입사월 기준 |
| 배치후 | 배치전 + 6개월 |
| 정기특검 | 특수항목 있는 직원, 전년도 동월 |

---

## 기능 2. 유해인자 자동 매핑

### 입력
- 부서(C열), 직군(D열), 직무(E열)

### 처리
1. `$HAZARD_MAP` 테이블에서 첫 매칭 규칙 적용
2. 야간(K열) = "O"이면 "야간, " 접두 추가
3. 특수항목(L열)과 유해인자(M열) 동시 업데이트

### 적용 대상
유해인자(M열)가 비어있거나 "X"인 행만 적용 (기존 입력값 보존)

---

## 실행 방법

```powershell
# 기본 실행 (27년 생성)
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
& ".\scripts\건강검진_27년이후_자동생성.ps1"

# 다른 연도 생성
& ".\scripts\건강검진_27년이후_자동생성.ps1" `
    -InputFile  ".\data\정기특검+보건증_27년이후.xlsx" `
    -OutputFile ".\data\정기특검+보건증_28년이후.xlsx" `
    -StartYear  28
```
