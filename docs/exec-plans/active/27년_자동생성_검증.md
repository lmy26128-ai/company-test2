# [진행중] 27년 자동생성 결과 검증

## 목표
`data/정기특검+보건증_27년이후.xlsx` 결과물의 정확성을 현업 담당자가 검토

## 작업 항목

- [ ] 생산1파트 샘플 10명 날짜 수동 비교
- [ ] 설비파트 유해인자 매핑 현업 확인
- [ ] 신규 입사자(26년) 배치전 날짜 적정성 검토
- [ ] 보건증 만료 예정자 별도 리스트 추출

## 기준 파일
- 입력: `data/정기특검+보건증.xlsx`
- 출력: `data/정기특검+보건증_27년이후.xlsx`
- 스크립트: `scripts/건강검진_27년이후_자동생성.ps1`
