# SECURITY.md — 개인정보 보안 정책

## 민감 데이터 현황

| 데이터 | 위치 | 민감도 |
|--------|------|--------|
| 주민번호 | `전체` 시트, 파트별 시트 | 최고 |
| 사번 | 전 시트 | 중간 |
| 성명 | 전 시트 | 중간 |
| 검진 결과 | 24.7기준최종 시트 | 중간 |

## 규칙

- `data/` 폴더 외부로 Excel 파일 복사 금지
- 주민번호가 포함된 시트(`전체`, 파트별)는 가공 작업 대상에서 제외
- 스크립트 출력(로그)에 개인정보 포함 금지
- 결과 파일 공유 시 주민번호 시트 삭제 후 배포

## 접근 제어

- `data/` 폴더: 담당자 PC 로컬 보관, 공유 드라이브 업로드 시 주민번호 시트 제거 필수
