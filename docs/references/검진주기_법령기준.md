# 검진 주기 법령 기준

> 산업안전보건법 제130조, 시행규칙 제195~208조 기준

## 검진 종류별 주기

| 검진 종류 | 주기 | 비고 |
|-----------|------|------|
| 일반건강검진 | 1년 | 사무직 2년, 비사무직 1년 (이 사업장은 1년 적용) |
| 배치전 특수검진 | 배치 전 1회 | 유해인자 노출 부서 배치 시 |
| 배치후 특수검진 | 배치 후 6개월 이내 1회 | 배치전 검진 후 6개월 기준 |
| 정기 특수검진 | 유해인자별 상이 (대부분 1년) | [별표 22] 기준 |

## 이 사업장 운영 원칙
- 전 직원 일반검진: **매년 4월** 기준 (특정 사유로 월 변경 가능)
- 정기특수검진: **전년도 동월** 기준 유지
- 배치전·배치후: **실제 배치 기준** 수기 입력 (자동생성 초안 후 담당자 확정)
