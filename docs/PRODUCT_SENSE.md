# PRODUCT_SENSE.md — 도구 목적과 사용자 관점

## 이 도구가 해결하는 문제

매년 연초에 전 직원 건강검진 일정을 수기로 계산하고 입력하는 작업:
- 610명 이상의 직원별 검진 유형(일반/특수) 구분
- 유해인자별 검진 주기 적용
- 배치전/배치후/정기특검 날짜 개별 산정
- 부서 이동·신규 입사자 반영

이 반복 작업을 **스크립트 1회 실행으로 자동화**합니다.

## 주 사용자

- 익산2공장 안전보건 담당자
- 인사/총무 담당자

## 사용 시나리오

1. **연초 일정 생성**: 매년 1월, 스크립트 실행 → 당해년도 검진 일정 일괄 생성
2. **신규 입사자 추가**: 원본 파일에 행 추가 후 스크립트 재실행
3. **유해인자 변경**: `$HAZARD_MAP` 수정 후 재실행
