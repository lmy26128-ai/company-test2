# QUALITY_SCORE.md — 데이터 품질 기준

## 자동생성 결과 검증 체크리스트

### 날짜 품질
- [ ] 일반검진 날짜가 `YY.MM` 형식인가
- [ ] 일반검진 대상자(J열=O) 전원에 27년 날짜가 생성되었는가
- [ ] 정기특검 날짜가 특수항목(L열) 있는 직원에만 생성되었는가
- [ ] 배치후 날짜가 배치전 날짜 +6개월과 일치하는가

### 유해인자 품질
- [ ] 생산직 중 유해인자 미입력자가 없는가
- [ ] 야간 근무자(K열=O)에 "야간" 접두가 포함되었는가
- [ ] 사무전문직 중 현장 미접촉자의 유해인자가 비어있거나 X인가
